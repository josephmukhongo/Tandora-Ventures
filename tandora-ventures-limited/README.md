> **Tagline**: "Connecting Opportunities. Powering Supply Chains."

## Key Features

1. **Verified Tender Discovery Engine**: Search active public and corporate tenders across Government Ministries, County Governments, NGOs, and Multinationals with authenticated original source links.
2. **Supplier Directory & Verification Matrix**: Directory of audited East African suppliers with KRA, KEBS, AGPO, and ISO compliance badges.
3. **Wholesale Products Catalog**: B2B product listings with wholesale pricing, MOQs, and origin country badges (Kenya, China, UAE, India, Europe).
4. **International Sourcing Hub**: Direct import trade desk connecting Kenyan organizations with OEM factories in Guangzhou, Dubai, and Mumbai.
5. **Logistics & Freight Hub**: Freight routes matrix and an interactive East Africa Freight & Import Tax Estimator.
6. **Interactive Business Portals**:
   - **Post an RFQ** multi-step creator wizard
   - **List Your Business** supplier onboarding wizard
   - **Sign In / Registration Modal** with role switcher (Buyer, Supplier, Admin)

## How to Make It Yours (Push to your own GitHub & Deploy to Vercel)

### 1. Create a New Repository on GitHub
1. Go to [GitHub.com](https://github.com) and sign in.
2. Click the **"+"** button at the top right -> **New repository**.
3. Name your repository `tandora-ventures-limited`.
4. Leave it empty (do NOT check "Initialize with README").
5. Click **Create repository**.
6. Copy the repository URL (e.g. `https://github.com/your-username/tandora-ventures-limited.git`).

### 2. Push Code to Your GitHub
In your local command line / terminal inside this project folder:

```bash
# Add your GitHub repository remote
git remote add origin https://github.com/your-username/tandora-ventures-limited.git

# Set main branch
git branch -M main

# Push all project files to GitHub
git push -u origin main
```

### 3. Deploy to Your Own Vercel Account
1. Log in to [Vercel.com](https://vercel.com).
2. Click **"Add New..."** -> **Project**.
3. Select your GitHub account and choose `tandora-ventures-limited`.
4. Click **Deploy**. Vercel will automatically build and deploy the project on your own custom domain or Vercel URL!
